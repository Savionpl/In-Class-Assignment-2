# In Class Assignment: JavaScript Variables & Conditional Statements 

## Instructions
Follow the steps below to complete the assignment in `script.js`.

### **Steps:**
1. **Declare a variable** and assign it a value.
2. **Print the variable's value to the console** using `console.log()`.
3. **Display the variable's value in an alert** using `alert()`.
4. **Use an `if` statement** to check the value of the variable:
   - If the condition is met, print a different message to the console.
5. **Test your script** by opening the index.html in the browser with Liveserver (right click)

### **Example Output**
When the script runs, you should see:
- A message printed in the console.
- A pop-up alert showing the variable’s value.
- A conditional message displayed in the console based on the variable’s value.
